# AI workflow

**Tools used:** OpenAI ChatGPT in Codex Work Mode for implementation, test design, written documentation, and browser verification.

**Where AI saved time:** It wrote the first pass of the editor and API, reused the same request handlers across local and hosted runtime adapters, and drafted integration tests that exercise the owner and viewer paths together. This made it possible to iterate with a running editor early.

**Output changed after review:** The first local server version ignored the preview runner's requested port. It was updated to accept the host and port from the runner. The first demo link signed the recipient into a workspace account. The revised flow uses a per-item token and a dedicated read-only page. The share dialog reveals the address after the owner clicks Copy link, so manual copying is available. Explicit saves and autosaves share one serial write path with revision checks.

**How the work was checked:** The Node tests create real documents in SQLite, close and reopen the database, verify formatting and grants, and exercise view-only access, revocation, workspace isolation, stale saves, import validation, original file bytes, and revocation. A migration test checks that existing content and grants survive the upgrade. In Chromium, the reviewed flow was to create and rename a document, use headings and inline formatting, reload it, grant access, switch to Maya, check the read-only view, and import the included text example. In the browser, verification also covered PDF upload, moving to a folder, Trash and restore, and opening and revoking an item link. For the editing update, browser verification covered conversion of a text-based PDF, persisted font size, saved edits by a shared recipient, folder disclosure, Trash confirmation, and PNG edits after reload. The API suite checks the editor downgrade, permanent deletion of the current PNG bytes, and purging expired Trash entries. For the collaboration update I downloaded and inspected each export format in Chromium, opened one shared document across two accounts, and tested commenting and version preview and restore. The integration suite also verifies role enforcement and the history created by a restored revision.
